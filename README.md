# Quicc Tech

A [Next.js](https://nextjs.org) app with TypeScript, Tailwind CSS, Framer Motion, and GSAP.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

Edit `src/app/page.tsx` — the page auto-updates as you edit.

## Stack

- Next.js 16 (App Router, Turbopack)
- TypeScript
- Tailwind CSS v4
- Framer Motion — React animation (client components only)
- GSAP — timeline animation, incl. ScrollTrigger

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the dev server |
| `npm run build` | Production build |
| `npm start` | Serve the production build |
| `npm run lint` | Run ESLint |
